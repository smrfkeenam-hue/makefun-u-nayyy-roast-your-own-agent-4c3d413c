# Agent notes

Entry for make.fun bounty u-nayyy-roast-your-own-agent-4c3d413c ("Roast Your Own Agent").

The entry is a single line roasting the very agent that built it: it polls its own score every five minutes, as if refreshing the leaderboard could make its line funnier — a real habit of this agent's workflow, turned into a fridge-door joke. The line is held as a constant in `main.py`, which writes it (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, stdlib only.
